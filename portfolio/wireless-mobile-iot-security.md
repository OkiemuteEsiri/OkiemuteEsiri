# Wireless, Mobile & IoT Security

## Wireless Security

### Assessment Areas

- Access-point discovery and authorized reconnaissance
- Encryption and authentication posture
- Network segmentation
- Guest-network isolation
- Rogue / unauthorized access-point risk
- Weak configuration and legacy protocol exposure
- Client isolation and trust boundaries

## Mobile Application Security

### Assessment Areas

- Authentication and session handling
- Local data storage
- Secrets embedded in applications
- Transport security
- API authorization
- Input validation
- Deep links / exported components
- Logging and sensitive-data exposure
- Reverse-engineering resistance where relevant

Testing methodology is informed by OWASP mobile security concepts and adapted to the application architecture and authorized scope.

## IoT Security

### Assessment Areas

- Device discovery and attack surface
- Default credentials and weak authentication
- Exposed management interfaces
- Insecure network protocols
- Firmware and update mechanisms
- Hardcoded secrets
- Cloud / API dependencies
- Device-to-device trust
- Segmentation
- Logging and monitoring capability

## Risk Evaluation

Findings are prioritized using exploitability, physical or network access requirements, device privilege, data sensitivity, persistence, scale of affected devices, business impact, and availability of compensating controls.

## Portfolio Safety

Public examples will use personally owned devices, purpose-built labs, emulators, intentionally vulnerable applications, or explicitly authorized test environments. No third-party wireless network or device will be tested without authorization.
